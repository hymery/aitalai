4.3 Анимации (реализовать ТОЧНО; WAAPI element.animate)
Вход экрана: герои выезжают с краёв (500ms, пружинка, второй с задержкой
120ms), чип сцены опускается (250ms), чат пуст.
Реплика персонажа:
1. t=0: герой «говорит» — scaleY 1 → 1.03 → 1 ×2 за 400ms + translateY −4px;
второй опускается на 4px.
2. t=0: у рта появляется индикатор печати — мини-облако с 3 точками (точки
прыгают по очереди, сдвиг 150ms), живёт 600ms.
3. t=600: индикатор превращается в облако реплики (ширина растёт 200ms), либо
создаётся реплика, как ниже.
4. Реплика «вылетает»: элемент добавлен в список, измерен
getBoundingClientRect() в конечной позиции; анимация transform от точки
рта (translate к рту, scale(.15), transform-origin:0 0) к none, 350ms, cubic-
bezier(.34,1.56,.64,1).
5. Параллельно лента сдвигается вверх на высоту нового облака (300ms), верхнее
облако уезжает под пол сцены.
6. Текст проявляется (translateY 6px → 0, 200ms).
Эскиз:

function say(side, node){                       // side: 'left' | 'right'
  list.append(node);
  const end = node.getBoundingClientRect();
  const m = mouthPoint(side);

scale(.15)`,transformOrigin:'0 0'},
                {transform:'none',transformOrigin:'0 0'}],
               {duration:350,easing:'cubic-
bezier(.34,1.56,.64,1)',fill:'both'});
  shiftList(); talkAnim(side);
}
Ответ игрока:
1. Тап по .choice →  .is-selected, активна «Проверить».
2. Тап «Проверить» →  остальные варианты уходят вниз (translateY 24px, 250ms),
выбранная плашка летит FLIP-ом (400ms) в слот левого облака, превращаясь в
облако игрока (скругление, цвет --blue-50); мальчик «говорит» (растяжка).
3. t=450: рамка облака →  зелёная/красная + иконка; верно — лист
«Верно»/«Точно»/«Так и есть»; неверно — shake 300ms, лист ошибки.
4. «Дальше»/«Понятно» →  лист вниз (250ms), индикатор печати у персонажа →
следующая реплика; новые варианты выезжают снизу (stagger 60ms).
5. Эмоции: верно →  оба happy (pop), неверно →  мальчик sad, персонаж
thinking; после «Понятно» возврат к нейтральной.
Idle: активный говорящий дышит (scaleY 1 → 1.015, 4s); prefers-reduced-
motion: без полётов/растяжек/дыхания, облака появляются мгновенно.
