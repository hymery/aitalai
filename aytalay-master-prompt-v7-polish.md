## 1. ОБЛАЧКА ПО ВСЕМУ ПРОЕКТУ: текст всегда помещается красиво

**Проблема:** где-то текст обрезается многоточием («Собираем предложе…»), где-то облако вытягивается вниз столбиком, где-то вылезает за край экрана. Исправить **единым компонентом `.cloud`** для ВСЕХ облаков (урок, диалог, квест, карта, библиотека, кабинет, рейтинг, награды).

### Правила (обязательные)
1. **Никаких обрезок:** в облаках запрещены `text-overflow:ellipsis`, `-webkit-line-clamp`, фиксированная высота, `overflow:hidden` на тексте. Многоточие допустимо только в строках списков (имя/школа), не в облаках.
2. **Ширина по содержимому:** `width:fit-content; min-width:96px; max-width:min(280px, calc(100vw - 2*var(--s3)))`. Перенос по словам: `white-space:normal; overflow-wrap:break-word; hyphens:manual; word-break:normal` (не `anywhere` — слова не рубим посреди).
3. **Автоподбор размера (функция `fitCloud(el)`, вызывать при показе, при ресайзе через `ResizeObserver` и после смены реплики):**
   - допустимо максимум **3 строки**; сначала уменьши шрифт ступенями 22 → 20 → 18 → 16px (меньше 16 нельзя, минимум 14 для 14-пиксельных пометок);
   - если на 16px всё равно > 3 строк — облако переключается в режим `.cloud--wide`: на **всю ширину** под маскотом (а не узкая колонка рядом);
   - ни при каких условиях не растягивать облако в высокий узкий столбик из 5+ строк.
4. **Не вылезает за экран:** после расчёта позиции JS ограничивает левый/правый край облака в `[8px, viewportWidth − 8px]`; **хвостик остаётся на рту/узле**, смещается внутри облака (`--tail-x`), а не двигает облако.
5. **Короткие тексты:** реплики маскота и подсказки ≤ 40 символов, один совет на облако. Названия уроков в облака **не помещать** (они в листе по тапу).
6. **Одинаковые отступы:** padding `--s3`; рамка 2px `--line`; радиус `--r-card`; нижняя грань 4px; хвостик — повёрнутый квадрат 16px с теми же рамками (две стороны), на рту героя.
7. Башкирский текст в облаке: `lang="ba"`, 20–22/800; если есть кнопка озвучки, она слева (круг 40px), текст справа с `min-width:0`.
8. Один вариант вёрстки на всё приложение: найди все самодельные облака (`.speech`, `.bubble`, пузыри на карте, реплики квеста, «Выбери книгу», «Ты начал!», «Заниматься — и ты в списке!») и переведи на `.cloud` с модификаторами `--left/--right/--wide/--bubble-node`.

## 2. КУРС (карта)

Что на скрине не так: пузырь «Начать · Собираем предложе…» обрезан и уходит за правый край; текущий узел со звездой упёрт в край; в центре стоит пара маскотов **поверх тропинки**; фон карты — белая плита с ромбами-звёздами (должны быть волны).

1. **Пузырь у текущего узла:** содержит **только слово «Начать»** (18/800 `--green-600`, `white-space:nowrap`, padding `--s2 --s3`). Название урока и детали — в листе по тапу (v2 §4.6), в пузыре его нет. Пузырь над узлом, по центру узла, но с зажимом в границах карты (§1.4), хвостик под центром узла. z-index: выше тропинки, ниже sticky-баннера.
2. **Узлы не упираются в край:** смещение `--dx` масштабируй: `k = min(1, maxDx / 64)`, где `maxDx = (ширина дорожки − 72)/2 − var(--s3) − 8` (8 — кольцо). Применяй `k` через CSS-переменную `--k` к каждому `--dx` (JS по `ResizeObserver`). Узел, кольцо и пузырь целиком внутри экрана с отступом ≥ `--s3`.
3. **Фон карты:** убрать белую плиту и ромбы/звёзды. Фон секции — волны (v4 §3) в цвете раздела (1 синий, 2 зелёный, 3 золотой); узлы стоят прямо на нём.
4. **Маскоты на карте:** никогда не поверх тропинки и узлов. Пару «мальчик+девочка» убрать из центра. Правило v3 §1.3: **одна фигура по пояс выглядывает из-за бокового края** в зазоре между узлами, с противоположной от изгиба тропинки стороны, видимая ширина 96–120px, отступ от узла/тропинки ≥ `--s3`. Пару показывать только как отдельную строку `.node-row--mascot` в начале/конце раздела (высота 140px, тропинка её обходит).
5. Boss-узел и нижний блок: нижний отступ ≥ высота навигации + `--s4` (последний узел не уходит под панель).

## 3. СООБЩЕСТВО — ГЛАВНЫЙ ЭКРАН (библиотека)

Что на скрине не так: маскот маленький (≈ 90px), стоит целиком и «парит»; облако «Выбери книгу» далеко от него; книги плоские, непонятно, что это книги; много пустоты.

### 3.1 Раскладка сверху вниз
```
[ карточка-шапка: «Китапхана переводов» + поиск + ряд башкирских букв ]
[ СЦЕНА: мальчик по пояс слева, облако справа от него ]  ← ≈ 150–170px
[ ШКАФ (paper): две толстые старые книги ]               ← занимает остаток высоты
```
- Шапка-карточка как сейчас; ряд букв Ү Ҡ Ғ Ҫ Ҙ Һ Ң: скроллбар **скрыть** (`scrollbar-width:none`, `::-webkit-scrollbar{display:none}`), справа/слева края не обрезают чипы (padding `--s3`, `scroll-padding`).
- **Маскот-мальчик:** увеличить: окно по пояс **≈ 150px высотой, ≈ 150px шириной**, слева, `data-emotion="happy"`, **выглядывает из-за верхней грани шкафа** (низ окна = верхний край шкафа, шкаф z-index выше). Облако «Выбери книгу» справа от него на уровне рта (`.cloud--right`, хвостик на рот, по правилам §1), `max-width` до края экрана.
- Если высоты экрана много — растёт шкаф/книги (`flex:1`), а не пустота; на высоких экранах книги до 300px.

### 3.2 Книги: толстые, широкие, старинные, с объёмом
Две книги в сетке `1fr 1fr`, `gap:var(--s3)`; каждая `aspect-ratio:4/5`, `max-height:300px`. Стиль остаётся плоским 2D (без blur/градиентов), но с **ступенчатым объёмом из плоских слоёв**:
- **Объём:** книга повёрнута через `perspective:900px; transform:rotateY(-14deg) rotateX(3deg)` (правая книга `+14deg`, зеркально), `transform-style:preserve-3d`. Слои: **передняя обложка**, **корешок** (слева, ширина 28px, чуть темнее, `rotateY(90deg)`), **блок страниц** справа и снизу (кремовые полосы `--paper`/`--paper-edge`, нарисованные SVG-`<pattern>` из тонких линий; **не CSS-градиент**), **верхний срез страниц**. Глубина ≈ 28px.
- **Обложка:** цвет — токены (`--blue-600` / `--green-600`), нижняя грань `--*-700` 8px. **Двойная золотая рамка** по краю (две линии 2px `--gold-500` с зазором 4px, отступ 12px от края), в центре — золотое тиснение-эмблема 64px (галочка в круге / перо), под ним название 22/800 и подпись 14px. **Потёртость:** по углам плоские светлые «заплатки» (`--blue-500` на синей, `--green-500` на зелёной) — маленькие скруглённые треугольники 20px.
- **Корешок:** 2–3 золотых «рёбра» (горизонтальные полосы 4px `--gold-500`) и по краям уголки-заглушки (`--gold-600`), как у старых книг.
- **Закладка-лента** свисает **снизу** из блока страниц на 24px (`--gold-500` или `--red-500`, плоская, зубчатый низ SVG), а не торчит сверху.
- Стоят на **шкафу-полке** (v5 §2.1): под каждой книгой плоская тень-полоса `--paper-edge` 8px.
- Нажатие (`:active`/`@media(hover:hover) :hover`): книга «выдвигается» вперёд `translateY(-6px) rotateY(-6deg)`, 150ms; тап → анимация открытия по v5 §2.3 (обложка с `backface-visibility:hidden`, внутренняя сторона обложки `--paper`).
- `prefers-reduced-motion`: без 3D-поворота, плоский вариант с тем же декором.

## 4. СООБЩЕСТВО — СТРАНИЦА ПРОВЕРКИ ПЕРЕВОДА (открытая книга)

Что на скрине не так: страница на весь экран, почти пустая (огромные зазоры над и под фразой), линейки идут «просто так», блок «Предложенный перевод» серый, не к месту.

### 4.1 Новая раскладка (flex-колонка на всю высоту оверлея; свободное место забирает зона маскота)
```
┌─ страница (--paper) ─────────────────────┐
│ [ленточка-прогресс 5 сегментов]    [ ✕ ] │  56px
│                                          │
│ ЗОНА МАСКОТА (flex:1, min 140px)         │  мальчик по пояс слева (120–160px),
│  [мальчик]  ( Как переведёшь? )          │  облако справа, реплики меняются
│                                          │
│ ───────── строка-линейка ─────────       │  
│  балалар билеты            [🔊]          │  фраза 32/800, `.text-ba`, на «строке»
│ ───────── строка-линейка ─────────       │
│  📖 Разговорник                          │  14px --ink-500
│                                          │
│ ┌ приклеенная записка ───────────────┐   │  «Предложенный перевод»
│ │ Предложенный перевод               │   │
│ │ детский билет                      │   │
│ └────────────────────────────────────┘   │
│ [   Верно   ] [  Неверно  ]              │  кнопки в ряд, 48px
│        Пропустить                         │  текстовая ссылка 44px
└──────────────────────────────────────────┘
```
- **Пустота исчезает:** лишняя высота уходит в зону маскота (`flex:1`), а контент (фраза, записка, кнопки) собран плотно вокруг. Расстояния между блоками — `--s3`/`--s4`, не больше.
- **Маскот:** мальчик по пояс, окно 120–160px, выглядывает из-за **нижнего края зоны**; облако рядом по правилам §1. Реплики (≤ 40 симв.), меняются по событию: старт «Как переведёшь?», «Верно» → «Так и есть!», «Неверно» → «Ничего, исправим», 3-я страница → «Ты уже на полпути». Анимация: выезд пружинкой, «говорит» (v4 §5.2).
- **Линейки:** не по всей странице, а только **две строки вокруг фразы** (верхняя и нижняя линия 2px `--paper-edge`, расстояние = высота строки текста + `--s2`); фраза стоит «на строке». Остальной фон страницы чистая `--paper`.
- **Записка вместо серого блока:** белая `--white` карточка, 2px `--paper-edge`, радиус `--r-card`, нижняя грань 4px, чуть повёрнута `rotate(-1deg)`, сверху «скотч» — плоский прямоугольник 48×16px `--gold-100` с рамкой 2px `--gold-500`, по центру. Подпись «Предложенный перевод» 14px `--ink-500`, перевод 22/800.
- **Кнопки:** `Верно` (`.btn-success`) и `Неверно` (`.btn-ghost`) в один ряд 1fr 1fr, gap `--s3`; ниже ссылка «Пропустить» (текстовая, не кнопка).
- Перелистывание/штамп/«Неверно»-поле — как v5 §2.4. При «Неверно» зона маскота сжимается (`flex` уменьшается), освобождая место под textarea, маскот остаётся виден (≥ 100px).
- Фон за книгой — волны, без больших колец/дуг.

## 5. РЕЙТИНГ

Что на скрине не так: две строки чипов (Ученики, Классы, Школы, **Точность, Словарь, Исправления**, Моя школа) налезают друг на друга; серая кнопка «Список» справа от заголовка; пьедестал без рамки; маскот «Заниматься — и ты в списке!» болтается отдельно; подзаголовки школ в 2 строки с городом; период перекрывает строки списка.

### 5.1 Раскладка сверху вниз
```
Рейтинг                                          (28/800, без кнопок справа)
[ Ученики | Классы | Школы | Моя школа ]         (один ряд, 4 равные колонки)
┌─ карточка пьедестала (2px рамка, радиус, грань 4px) ─┐
│   волна-небо + пьедестал 2–1–3                       │
│──────────────────────────────────────────────────────│
│ [ Неделя | Месяц | Всё время ]                       │  сегмент внутри карточки, внизу
└──────────────────────────────────────────────────────┘
Другие участники                                  (16/800)
[ строка 4 ] [ строка 5 ] …                       (до 5 строк)
```
- **Вкладки:** только **4**: «Ученики · Классы · Школы · Моя школа» (одна строка, `grid-template-columns:repeat(4,1fr)`, 15/800, `nowrap`, текст влезает; индикатор-подчёркивание скользит). **Удалить** чипы «Точность», «Словарь», «Исправления» (и любые другие метрики) и кнопку «Список». Единственная метрика — очки.
- **Пьедестал в отдельной рамке:** `.podium-card` — белая карточка (2px `--line`, `--r-card`, нижняя грань 4px, `overflow:hidden`), внутри небо-волна `--blue-50`, ступени 2–1–3 (v5 §3.1), без вылезаний. Нижней полосой внутри карточки (отделена линией 2px `--line`) идёт сегмент периода **«Неделя · Месяц · Всё время»** — прямо под ступенями. Он больше **не липкий внизу экрана** и ничего не перекрывает.
- **Маскот удалить** (и облако «Заниматься — и ты в списке!»): он здесь не нужен. Если участников после топ-3 нет — блок «Другие участники» просто скрыт.
- **Строки списка:** `.rank-row`: место, аватар 40px, имя **с заглавной буквы** (нормализуй: «гелдис к.» → «Гелдис К.»; каждое слово с заглавной), справа очки+сота. Подпись «школа · класс» **одной строкой с ellipsis** (допустимо в списках), **без города** (убрать фрагменты «г. …»), кавычки школы нормализуй. Строка пользователя — `--blue-50` + рамка `--blue-500`. Список не перекрывается ничем; нижний отступ ≥ высота навигации + `--s4`.
- Анимации перетекания (v5 §3.2) сохранить; сегмент периода внутри карточки скользит пилюлей.

## 6. КАБИНЕТ — КАРТОЧКА «СЕРИЯ»

На скрине текст «Позанимайся сегодня, чтобы начать серию» зажат в узкую колонку (5 строк), «дней подряд» стоит сбоку, кнопка «К урокам» прижата справа и «плавает».

Новая раскладка карточки (вертикальная колонка, всё выровнено по левому краю, `gap:var(--s3)`, padding `--s3`):
```
┌─ карточка (--gold-50, рамка --gold-500) ────────┐
│ [🔥 48px]  0                                    │  ряд: огонь + число 32/800, align-items:center
│ дней подряд                                     │  14px --ink-500, ПОД огнём и числом, left = левый край огня
│                                                 │
│ Позанимайся сегодня, чтобы начать серию         │  16/700 --ink-900, во всю ширину, 1–2 строки, горизонтально
│ [            К урокам            ]              │  .btn-primary, высота 48px, на всю ширину карточки
└─────────────────────────────────────────────────┘
```
- Текст идёт **одной горизонтальной строкой/двумя**, не колонкой; `max-width:100%`.
- Кнопка «К урокам» — `.btn-primary.btn-block` (48px, на всю ширину карточки), единственная главная кнопка блока; ведёт на «Курс».
- Серия > 0: вместо текста и кнопки — неделя из 7 кружков (v6 §5.1), число и подпись «дней подряд» вверху так же (огонь → число, под ними подпись).
- Облачко «Ты начал!» в блоке «Ближайшая награда» — по правилам §1 (маскот чуть больше: окно по пояс 96–110px, облако с `fit-content`).

## 7. САМОПРОВЕРКА (отметь в CHANGELOG.md)
1. «Әйтәләй» везде в UI/мета/боте/styleguide; внутренние ключи не тронуты.
2. Ни в одном облаке нет «…», нет высоких узких столбиков (>3 строк), ни одно облако не выходит за экран; все облака — компонент `.cloud` с `fitCloud`.
3. Карта: пузырь «Начать» целиком, внутри экрана; узлы не упираются в края; волновой фон; маскоты не поверх тропинки.
4. Библиотека: маскот-мальчик по пояс ~150px выглядывает из-за шкафа, облако у его рта; книги толстые/старинные с корешком, страницами, золотой рамкой, закладкой; нет пустых дыр.
5. Страница проверки: нет больших пустот — зона маскота, фраза на «строке», записка со скотчем, кнопки в ряд.
6. Рейтинг: 4 вкладки в один ряд, нет метрик и кнопки «Список»; пьедестал в рамке с периодом под ступенями; маскота нет; имена с заглавных, подписи одной строкой без города.
