# Tuna 0.40.0

Консольная утилита для организации HTTP/TCP туннелей в локальную сеть.  

## Установка

Tuna распространяется одним файлом и не требует специальных знаний для установки, достаточно скопировать файл из архива по пути:

```sh
sudo mv ./tuna /usr/local/bin/tuna
sudo chmod +x /usr/local/bin/tuna
```

Скопируйте токен из личного кабинета и сохраните его вместо того, чтобы постоянного указывать его в аргументах запуска:

```sh
tuna config save-token tt_g1d6vd9dv6h2n4y4tv9mz10123456789
```

Самое время приступить к работе, запустите tuna с передачей порта и делитесь ссылкой с коллегами:

```sh
tuna http 8080
```
